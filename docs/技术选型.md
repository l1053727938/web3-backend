# web3-backend 技术选型文档

> 面向 Web3j 以太坊后端应用（钱包/充值提币/链上数据查询场景）的完整技术选型与落地说明。
> 本文档与项目当前骨架代码一一对应。

## 一、选型总览

| 层面 | 选型 | 版本 | 在项目中的职责 |
|---|---|---|---|
| 语言/运行时 | JDK | 21 (LTS) | 虚拟线程收益（大量链上 RPC 阻塞调用）、新版 GC |
| 应用框架 | Spring Boot | 3.5.5 | Web 容器、依赖注入、配置管理 |
| 链交互库 | Web3j | 4.12.3 | JSON-RPC 调用、钱包/密钥管理、ABI 编解码、事件订阅、合约包装类 |
| 链节点接入 | Infura | — | 托管 RPC 节点（HTTP + WebSocket），免自建节点 |
| 构建工具 | Maven | 3.9.x | 依赖管理与打包（spring-boot-maven-plugin） |
| ORM | MyBatis-Plus | 3.5.9（spring-boot3-starter） | 流水/扫描进度等持久化，`BaseMapper` + `LambdaQueryWrapper` |
| 数据库 | MySQL | 8.x | 区块扫描进度（`block_sync_state`）、充值提币流水 |
| 缓存 | Redis | 7.x | 热点数据缓存、分布式协调 |
| 分布式锁 | Redisson | 3.41.0 | 多实例区块扫描互斥、提币防重 |
| RPC 容错 | Resilience4j | 2.2.0 | Infura 调用重试（`@Retry`）与熔断（`@CircuitBreaker`） |
| 任务调度 | Spring Scheduler + XXL-Job | 2.4.2（可选） | 默认 Spring 定时扫块；分布式部署时切换 XXL-Job 补扫 |
| API 文档 | SpringDoc OpenAPI | 2.8.5 | Swagger UI：`/swagger-ui.html` |
| 监控 | Actuator + Micrometer + Prometheus | Boot BOM 管理 | 指标暴露：`/actuator/prometheus` |
| 集成测试 | JUnit 5 + Web3j Test | — | `org.web3j:test`（TestnetSetup 内嵌临时链） |
| 编码简化 | Lombok | Boot BOM 管理 | `@Data`/`@RequiredArgsConstructor`/`@Slf4j` |

## 四、关键设计说明

### 4.1 链上交互（Web3j + Infura）
- `Web3jConfig` 基于 `HttpService(infura-http-url)` 构建单例 `Web3j`，`destroyMethod = "shutdown"` 保证退出时释放 OkHttp 连接池。
- Infura Project ID 通过环境变量 `INFURA_PROJECT_ID` 注入，**不写入代码库**。
- 默认对接 **Sepolia 测试网**（chainId=11155111）；切主网改 `web3.infura.*` 的 URL 与 chainId 即可。
- 事件订阅（后续充值到账监听）使用 `ws-url` 构建 `WebSocketService`，配合 `web3j.ethLogObservable` / `Filter`。

### 4.2 RPC 容错（Resilience4j）
- 所有链上查询方法标注 `@Retry(name = "rpc")` + `@CircuitBreaker(name = "rpc")`。
- 策略：最多重试 3 次（间隔 500ms）；滑动窗口 20，失败率 ≥50% 熔断 30s。
- 兜底由 `GlobalExceptionHandler` 统一转 `502` 响应。

### 4.3 区块扫描（Scheduler + XXL-Job + Redisson）
- `BlockScanner` 每 30s（`web3.scanner.interval-ms`）轮询最新区块高度，进度写入 `block_sync_state`。
- **双通道**：默认 Spring Scheduler 触发；`XXL_JOB_ENABLED=true` 时可由 XXL-Job 调度中心触发 `blockScanHandler`，适合多实例/失败重跑。
- **Redisson `tryLock`** 保证多实例部署仅一个节点执行，未抢到锁直接跳过本轮。

### 4.4 安全与密钥管理
- 私钥严禁硬编码：本地开发用环境变量/`.env`（勿提交），生产建议 HashiCorp Vault 或托管钱包服务（Fireblocks/Turnkey）。
- 钱包文件（keystore）已在 `.gitignore` 中排除（`wallet/`、`*.keystore`）。

### 4.5 监控
- `/actuator/health` 探活；`/actuator/prometheus` 暴露 JVM、HTTP、Resilience4j 熔断器状态指标。
- 建议告警项：RPC 失败率、区块扫描滞后高度（`block_sync_state` 与链上最新块差值）。

## 五、环境要求与启动步骤

### 5.1 环境要求
| 组件 | 要求 |
|---|---|
| JDK | 21（本机 `JAVA_HOME` 需指向 JDK 21，IDEA 中 Project SDK 同步切换） |
| Maven | 3.9.x |
| MySQL | 8.x，执行 `sql/schema.sql` |
| Redis | 7.x |
| Infura 账号 | 创建 Project 获取 `projectId`（infura.io 免费额度可覆盖开发） |

### 5.2 启动（PowerShell）
```powershell
# 1. 注入 Infura 项目 ID
$env:INFURA_PROJECT_ID = "你的projectId"

# 2. 编译打包
mvn clean package -DskipTests

# 3. 启动
java -jar target/web3-backend-1.0.0-SNAPSHOT.jar
```

### 5.3 验证
| 入口 | 地址 |
|---|---|
| 链上状态 | `GET http://localhost:8080/api/chain/status` |
| 最新区块 | `GET http://localhost:8080/api/chain/block-number` |
| 地址余额 | `GET http://localhost:8080/api/chain/balance/{address}` |
| Swagger UI | `http://localhost:8080/swagger-ui.html` |
| Prometheus 指标 | `http://localhost:8080/actuator/prometheus` |

## 六、后续开发计划

1. **ERC20 合约交互**：`web3j-maven-plugin` 从 ABI/Solidity 生成合约 Java 包装类；转账/授权走 `TransactionManager` + nonce 管理。
2. **充值监听**：WebSocket 订阅 Transfer 事件 + 按块高补偿扫描（应对节点重组）。
3. **提币服务**：Redisson 锁防重 + 交易回执轮询确认 + Resilience4j 限流。
4. **多链扩展**：按 chainId 配置多个 `Web3j` 实例（`Map<Long, Web3j>` 路由），EVM 兼容链（BSC/Polygon/Arbitrum）复用同一套代码。
5. **托管钱包**：引入 Vault 或 MPC 钱包服务替代本地 keystore。
